# Data

Large datasets are **not** stored in this repository. Download or generate them with the scripts in `scripts/`.

## 1. Vehicle Energy Dataset (VED): real data

- **Source:** https://github.com/gsoh/VED
- **Content:** OBD-II driving logs (speed, RPM, temperatures, fuel and battery data) from a fleet of ICE, hybrid and electric vehicles
- **Location:** `data/raw/`
- **Citation:** if you use VED, cite the paper listed in its repository README

## 2. Synthetic fault logs: generated

- **Source:** generated by this project
- **Content:** sensor logs with injected faults (e.g. overheating, misfire, voltage drop) and their matching DTCs, so every fault is labeled
- **Location:** `data/synthetic/`

## Reference: DTC table

- **Location:** `data/reference/`
- **Content:** common OBD-II fault codes (SAE J2012 generic codes) with descriptions, severity and likely causes

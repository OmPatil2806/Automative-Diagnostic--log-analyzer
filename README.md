# Automotive Diagnostic Log Analyzer

Turn raw vehicle diagnostic logs into clear, actionable insights: decode fault codes, detect abnormal sensor behavior with machine learning, and visualize vehicle health.

## Problem

Modern vehicles record huge amounts of diagnostic data (sensor readings and Diagnostic Trouble Codes, or DTCs), but this data is:

- **Too large** to inspect by hand
- **Cryptic**: codes like `P0301` mean nothing without a reference
- **Reactive**: a DTC usually appears only *after* a fault has occurred
- **Hard to trace**: one fault can trigger several codes, hiding the real root cause

As a result, diagnosis is slow, parts get replaced by trial and error, and early warning signs are missed.

## Solution

An analyzer that:

1. **Parses** OBD-II logs into clean, structured data
2. **Decodes** DTCs into plain English with severity levels
3. **Detects anomalies** in sensor signals with ML, before a fault code appears
4. **Correlates** abnormal signals with the faults that follow them
5. **Visualizes** results in a dashboard: fault timeline, signal plots and a vehicle health score

## Data

The project uses two data sources (see [`data/README.md`](data/README.md)):

| Data | Type | Purpose |
|---|---|---|
| [Vehicle Energy Dataset (VED)](https://github.com/gsoh/VED) | Real OBD-II logs | Learn normal vehicle behavior, analysis and visualization |
| Synthetic fault logs | Generated by this project | Labeled faults for testing detection and root-cause analysis |

A small DTC reference table (`data/reference/`) is used for decoding fault codes.

## Getting started

```bash
git clone https://github.com/OmPatil2806/Automative-Diagnostic--log-analyzer.git
cd Automative-Diagnostic--log-analyzer
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. Download VED (use --weeks N for a smaller sample; all 54 weeks is about 3 GB)
python scripts/download_ved.py --weeks 4

# 2. Clean it -> data/processed/ved_clean.parquet
python scripts/prepare_ved.py

# 3. Inject faults -> data/synthetic/
python scripts/generate_synthetic.py

# Run tests
pytest
```
